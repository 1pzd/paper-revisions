133: 3.7 Baseline Implementation and Evaluation Protocol
134: 
135: To ensure fair comparison, all baselines were re-implemented and trained on the identical train/validation/test split (1171/167/335 images) described in §3.6. All methods use the same data preprocessing (resize to 224×224, horizontal flip, mild color jitter), the same evaluation metrics (accuracy, MSE_exp, Kappa), and the same aggregation protocol (average over 3 runs with random seeds 42, 123, and 2024). Hyperparameters for each baseline were selected via grid search on the validation set, optimizing for accuracy. All models were trained for 50 epochs with early stopping based on validation accuracy, using AdamW optimizer with weight decay 0.01 and cosine annealing learning rate schedule.
136: 
137: Generic backbones (ResNet50, DenseNet121, ViT-B/16) were implemented via PyTorch timm library with ImageNet-1k pretrained weights. The final classification layer was replaced with a 6-way linear head and trained end-to-end. Learning rates were searched in {1e-5, 5e-5, 1e-4, 5e-4}, batch size 8 due to GPU memory constraints. ResNet50 used lr=1e-4, DenseNet121 used lr=5e-5, ViT-B/16 used lr=5e-5.
138: 
139: CLIP baselines used the official OpenAI ViT-L/14 checkpoint. Zero-shot inference applied the six grade-specific prompts from §3.3.2 without any training. Linear probing froze the image encoder and trained only a linear classifier on top of the [CLS] token features for 50 epochs with lr=1e-3.
140: 
141: ResNet50+CORAL replicated the rank-consistent ordinal regression method (7) by attaching CORAL loss to a ResNet50 backbone (ImageNet pretrained). We used the official implementation from the paper's repository, with lr=1e-4 and the same data split.
142: 
143: CDRFF-Net and LOCS III hybrid are task-specific methods designed for cataract grading (4,5). Both papers report results on private datasets with different LOCS III labeling protocols and do not provide public code. We re-implemented both architectures based on the method descriptions in the papers: CDRFF-Net uses a discriminative region feature fusion network with ordinal regression, and LOCS III hybrid combines nuclear color and cortical opacity predictions via a multi-task learning framework. Both were trained on our dataset with the same 50-epoch protocol, lr=1e-4, and hyperparameters tuned on the validation set. The reported results (83.10% and 82.65%) reflect our in-house reproduction on our data split, not the original paper values.
144: 
145: All baseline results in Table 1 are therefore directly comparable to CLIP-CAT, as they were trained and evaluated under identical conditions on the same dataset split.

147: 3.8 Evaluation Protocol and Reporting
148: 
149: We report results from two independent evaluation procedures to assess both performance and generalization stability.
150: 
151: Primary evaluation (fixed split): The dataset is divided into training (1171 images, 70%), validation (167 images, 10%), and test (335 images, 20%) subsets via stratified random sampling. This split is FIXED across all experiments. For each method, we train three independent models with different random seeds 42, 123, and 2024, each starting from the same pretrained weights but with different weight initialization for newly added layers and different data augmentation randomness. Each model is trained for 50 epochs, with checkpoint selection based on validation accuracy. The three trained models are then evaluated on the held-out test set, producing three sets of predictions. Table 1 reports the mean ± standard deviation of accuracy, MSE_exp, and Kappa across these three runs. Tables 3-4 display results from a SINGLE representative run (seed 42) to show the detailed per-grade breakdown and error distribution. The discrete-grade MSE_hard = 0.17 in Section 4.3 is computed from this single-run confusion matrix.
152: 
153: Cross-validation (generalization check): To verify that the fixed-split results do not depend on a favorable train/test partition, we repeat the entire experiment with 5-fold stratified cross-validation over the full 1673-image dataset. Each fold uses 80% for training, 20% for testing, with no validation set (checkpoint selection uses training loss). For each fold, we train ONE model (seed 42 only, not averaged over 3 seeds) and evaluate on that fold's test set. We report the mean ± standard deviation of accuracy, MSE_exp, and Kappa across the 5 folds in Section 4.4 (86.1% ± 0.85%, MSE 0.45 ± 0.05, Kappa 0.87 ± 0.02). The 5-fold results are INDEPENDENT of the fixed-split results: no image in the fixed test set is used for training in the primary evaluation, and the 5-fold procedure reuses all images across different folds. The purpose of 5-fold CV is to demonstrate stability across different data partitions, not to replace the fixed-split evaluation.
154: 
155: Unless explicitly stated otherwise, all results in Section 4.1-4.3 refer to the primary fixed-split evaluation with 3-run averaging (Table 1) or single-run details (Tables 3-4).
